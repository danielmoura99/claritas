# Panel

Surface container for every terminal module — header with eyebrow/title/actions, body, optional footer.

```jsx
<Panel eyebrow="Watchlist" title="Ibovespa" actions={<IconButton icon="plus" label="Adicionar" size="sm" />} padding={false}>…</Panel>
```

- `glow="sand"` while Claritas is actively writing into the panel. Don't nest Panels.
