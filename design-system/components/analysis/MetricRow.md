# MetricRow

Key-value line for analysis summaries (regime, risco/retorno, nível-chave, próximo alvo, sinais-chave); value fades when it changes.

```jsx
<MetricRow icon="trending-up" label="Regime atual" value="Tendência de alta" />
<MetricRow icon="target" label="Próximo alvo" value="39,20" sub="+2,1%" />
```
